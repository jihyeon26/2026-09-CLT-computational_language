# WP2 relation manual review

This folder contains the reproducible manual-review sample for Stage 1 WP2 relation extraction.

## Files

- `relation_review_sample_seed42.csv`: 90 unique GLiREL triples selected with seed 42
- `sampling_manifest.json`: input hashes, population filters, sampling method and sample distribution

The sample is generated by `scripts/sample_wp2_relation_review.py` from the official WP2 handover in
`outputs/stage1_wp2_open_models_official_20261007/`.

## Review assignment

The sample contains 30 rows each for `Reviewer_A`, `Reviewer_B` and `Reviewer_C`. Replace these labels
with team members' names if desired, but do not change the extracted relation or evidence columns.

Each reviewer completes these columns:

- `review_correct`: `TRUE`, `FALSE` or `AMBIGUOUS`
- `reviewer`: reviewer name or agreed team ID
- `review_error_type`: required when `review_correct` is `FALSE`
- `review_notes`: short reason, correction or explanation of ambiguity

Accepted error types:

- `entity_boundary`
- `entity_linking`
- `wrong_predicate`
- `reversed_direction`
- `negation_or_uncertainty`
- `insufficient_context`
- `duplicate_or_noise`
- `schema_or_catalogue`
- `other`

Use `AMBIGUOUS` when the evidence sentence is insufficient to decide. Precision is calculated as
`TRUE / (TRUE + FALSE)`; ambiguous rows are reported separately.

## Sampling scope

The sampling unit is one unique `(head_id, predicate, tail_id)` triple. The population contains only
GLiREL triples that:

- passed the original WP2 type check;
- remain valid under the final node types in `nodes.csv`;
- occur in at least two evidence sentences; and
- are not self-relations.

At least two rows are sampled per relation type when available. Remaining rows are allocated across
mean-confidence bands. One evidence sentence is selected deterministically for each sampled triple.

The 35 curated `wp1_lexicon` relations are excluded because they do not have article-level evidence in
the handover. They should be checked separately against the WP1 family-to-developer mapping.

## Reproduce the sample

```powershell
.\.venv\Scripts\python.exe scripts\sample_wp2_relation_review.py `
  --sample-size 90 `
  --seed 42
```

Running the command against unchanged inputs produces the same relation and evidence selections. The
manifest records hashes for all input files and the generated CSV.

## Summarize completed reviews

After completing the review columns, save the file as `relation_review_completed.csv` and run:

```powershell
.\.venv\Scripts\python.exe scripts\summarize_relation_reviews.py `
  --reviews artifacts\stage1_wp2\evaluation\relation_review_completed.csv `
  --output-dir artifacts\stage1_wp2\evaluation\summary `
  --minimum-reviewed 90 `
  --minimum-precision 0.80 `
  --fail-on pending
```
